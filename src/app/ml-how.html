{{i:cpu}}How ML works here{{i:chev}}

All three models run client-side, in the browser. The server never trains or runs a model.

  1. {{i:store}}Recommender · cosine similarityItem-to-item collaborative filtering blended with product attribute vectors, computed in the buyer’s browser on the shop page.
  2. {{i:chart}}Fair-price MLP · TensorFlow.jsAn 8→32→16→2 network trained in the seller’s browser in Seller Studio. It predicts a fair price and weekly orders.
  3. {{i:camera}}Photo tagger · MobileNet CNNA pre-trained ImageNet model that tags the product photo in AI Catalogue. The photo stays on the device until the seller publishes it.
{{i:database}}Node.js + SQLite server {{i:arrow}}real order baskets → recommender {{i:arrow}}sales CSVs the admin imports → price MLP
